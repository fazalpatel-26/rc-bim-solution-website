RC BIM Solution — Static Website Test Package

Contents: index.html, style.css, script.js, assets/

1) Unzip and test index.html locally in a browser.
2) To use GitHub, upload the CONTENTS of this folder to the root of a repository (not the ZIP itself).
3) For Hostinger public_html deployment, upload the CONTENTS of this folder (index.html at root).
4) For a safe staging test, use Hostinger staging/temporary domain or a subdomain with its own document root. Do NOT overwrite WordPress yet.
5) Contact form opens WhatsApp with a pre-filled message; it DOES NOT send an email or store submissions.
6) Portfolio images were extracted from the user-supplied Zurich portfolio with permission as stated.
7) Privacy and legal copy are drafts. Review before launch.
8) For future edits, change index.html / style.css, commit and redeploy.
